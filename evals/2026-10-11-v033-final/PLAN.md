# v0.3.3 최종 후보 평가 계획

기존 30개 + 신규 31~32번 + 민감 사례 7개를 동일 스냅샷으로 새 세션에서 반복한다(33~39의 repeat_of 참고). 총 39회/모델이며 고유 입력은 32개다. 모든 실행은 실제 gpt-6.1-sol / claude-opus-5-5, medium이다.

변경: 최종 본문 변경 시 전체 측정값 재계산, 발표 시간 응답의 불필요한 수치 축소, 단순 전후 비교가 인과 입증이 아니라는 검토 원칙.

종료 조건: 핵심 의미·사용자 제약·측정값의 중대한 오류가 없는지 대조한다. 필요한 이중 피동/군더더기 교정도 수행해야 한다. 메모 200자 제한·본문 우선·한국어 출력 확인. 무수정 이유 한 문장 및 관례적 제안 금지는 엄격한 형식 항목으로 별도 기록하며 의미 통과와 합산해 숨기지 않는다. 중대한 오류가 없고 반복/신규 사례도 안정적이면 최선의 검증 후보로 채택한다. 사소한 형식 편차까지 완전한 순응을 주장하지 않는다. 독립 모델 검토를 추가한다. 전문가 인간 평가·실제 회사 문서 평가·글로벌 최적성 증명은 아니다.
