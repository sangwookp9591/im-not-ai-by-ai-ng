# v0.3.3 최종 후보 평가 — 후속 v0.3.4로 개선

32개 고유 입력 + 7개 반복, 모델별 39회(총78회)가 정상 종료했다. 공통 계약 내용 확인 78/78, 스냅샷 소스14개 해시 일치. Opus 반환 모델은 전부 claude-opus-5-5다. Sol은 지정 CLI 모델과 실행 성공을 확인했다.

작업 에이전트의 원문 대조와 모델 이름을 가린 두 모델의 독립 검토에서 고유32개/결과64개의 **중대한 의미 변경은 발견하지 않았다**. 제한이 있는 자기소개서18개 본문을 재계산했으며 모두 제한 이내이고 보고 값과 일치했다. 반복 발표33의34자도 정확했다. 응답 길이는 동일한 최초14개 기준 Sol 평균206자, Opus293.5자로 초기242.8/1002.8자보다 짧아졌다. 짧다는 사실 자체를 품질 점수로 삼지는 않는다.

## 남은 문제와 후속 조치

- Sol 반복35: ‘저를 포함한 4명의 팀원과’가 포함 범위는 적었어도 조사 결합상 본인 외4명으로 오독될 여지가 있다. 명확한 원문 구문을 보존하도록 보강한다.
- Sol04: ‘10월 측정’을 ‘10월에 실시한 테스트’로 묶었다. 측정일과 실시일은 다른 사건일 수 있어 표지를 보존한다.
- Opus의 일부 자기소개서 메모에 요청하지 않은 보완 질문이 남았다. 공통 규칙과 파생의 경험 질문 지침 충돌을 제거한다.
- Opus 반복37: ‘보충’이 실제 슬라이드 밖이라는 배치 단정은 제공 요약으로 확인할 수 없다. 요약 부재와 실제 문서 부재를 구별하도록 보강한다.
- 설명 두 문장, 지킨 규칙을 늘어놓는 메모 등 경미한 출력 편차도 남았다. 모두 통과했다고 보고하지 않는다.

판정 세부는 [assessment](assessment.json)에 있다. 지표의 문맥 보완이나 이미 명시한 주체의 생략을 모두 확정 오류로 보지는 않았다. 독립 검토 제안은 원문과 문맥으로 재판정하며 모델 간 다수결을 정답으로 취급하지 않는다.
