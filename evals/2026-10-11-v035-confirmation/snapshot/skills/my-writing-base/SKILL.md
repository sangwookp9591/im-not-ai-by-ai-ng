# 나의 기본 글쓰기 스킬

[공통 계약](references/core.md)을 먼저 읽는다. 일반 글쓰기 요청은 이 계약으로 직접 처리한다. 특별한 용도가 명확하면 아래의 해당 파생 스킬을 읽고 그 절차를 따른다. 기본 스킬은 모든 타입 규칙을 한꺼번에 읽지 않는다.

| 용도 | 파생 스킬 |
|---|---|
| 기획안·요구사항·의사결정 문서 | [my-planning](../my-planning/SKILL.md) |
| PPT 화면의 제목·불릿·표기 | [my-slides](../my-slides/SKILL.md) |
| 여러 장의 메시지·근거·흐름 | [my-presentation](../my-presentation/SKILL.md) |
| 말할 대본·호흡·낭독 시간 | [my-speech](../my-speech/SKILL.md) |
| 지원동기·문항별 경험·직무 연결 | [my-application](../my-application/SKILL.md) |

파생 스킬은 공통 계약을 직접 참조한다. 같은 실행에서 이미 읽었으면 중복 로드하지 않는다. 사용자에게 목적이 명확한 경우 스킬 선택 질문을 하지 않는다. 혼합 문서는 해당 구획에 필요한 파생 규칙만 적용한다.

기본 계약 수정은 references/core.md 한 곳에서 한다. 개인 취향은 명시적으로 받은 것만 반영하고, 한 용도의 예외를 모든 글에 일반화하지 않는다. 새 파생 스킬 추가 방법은 플러그인 README에 있다.
