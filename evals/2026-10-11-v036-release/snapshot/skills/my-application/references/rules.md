# 자기소개서

문항에 답하는지, 지원자의 실제 경험과 직무의 연결이 구체적인지 판단한다. 자기소개서는 영문 cover letter와 형식이 다르므로 한국 기업의 문항·분량·양식을 우선한다.

- 지원 직무, 문항, 공백 포함 여부, 제한 글자 수, 제공된 경험을 확인한다. 제공된 사실로 문체 교정이 가능하면 추가 경험을 묻지 않는다. 내용 보강을 요청받았거나 문항 작성 자체가 불가능할 때만 필요한 경험을 질문한다.
- 경험을 상황/과제→본인의 행동→확인된 결과→직무 관련성으로 점검하되 모든 문항에 동일한 네 단락을 강제하지 않는다. 지원동기·가치관 문항의 목적을 따른다.
- 팀 성과와 본인 기여를 구별한다. “지원했다”를 “주도했다”로, “참여했다”를 “설계했다”로 올리지 않는다. 수상·기간·인원·매출·개선율·역할을 창작하지 않는다.
- “열정적”, “소통 역량” 같은 자기평가를 줄일 때는 이미 제공된 행동을 활용한다. 행동 근거가 없으면 꾸며내지 않는다. 개인적인 어휘와 경험의 차별성을 보존한다.
- 기업의 최근 소식이나 사업 전략을 새로 활용해야 한다면 공식 출처를 확인하고 출처를 검토 메모에 남긴다. 이름만 바꿔 어디든 제출할 수 있는 동기를 피한다.
- 글자 수는 제출할 답변만 문항별로 도구로 센다. 소제목 포함 여부와 줄바꿈 규정을 확인한다. 플랫폼 수치가 다르면 플랫폼을 기준으로 한다.

검증: 문항에 직접 답하는가; 주장마다 지원자가 제공한 경험이 있는가; 팀/개인 기여와 성과가 보존되는가; 문항별 제한을 맞췄는가.

예시(합성): “팀 프로젝트에서 인터뷰 일정 조율을 맡았습니다.”를 “고객 조사 전체를 주도했습니다.”로 바꾸면 역할 과장이다. 문체 교정이면 원문을 유지한다. 사용자가 내용 보강을 요청한 경우에만 일정 조율의 구체 행동을 묻는다.

참고: [Oxford Cover letters](https://www.ox.ac.uk/careers/careers-guidance/job-search-and-applications/writing-applications/cover-letters). 직무와 경험 연결 원칙만 참고하며 영문 편지 형식·A4 1쪽 기준을 한국 자기소개서에 적용하지 않는다. 국내 직무별 실증 검증은 아직 없다.
