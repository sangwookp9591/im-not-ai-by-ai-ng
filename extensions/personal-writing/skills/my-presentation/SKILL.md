# 나의 프레젠테이션 구성 스킬

## 기본 계약 상속

작업 전에 [공통 계약](../my-writing-base/references/core.md)을 읽고, 이어서 [용도별 규칙](references/rules.md)을 읽는다. 공통 계약은 복사하거나 새로 정의하지 않는다. 상대경로는 현재 작업 폴더가 아니라 이 SKILL.md의 디렉터리를 기준으로 해석한다.

기본 스킬의 SKILL.md를 다시 호출할 필요는 없다. 공통 계약 파일을 직접 읽어 순환 라우팅을 피한다. 기본 파일이 없으면 손상된 설치임을 알리고 전체 skills 묶음 복원을 요청한다. 기억으로 공통 규칙을 대체하지 않는다.

사용자의 요청과 제공된 양식을 우선한다. 기본 계약의 사실 보존과 수정 범위를 지키면서 용도 규칙을 적용한다. 용도 규칙은 구조·독자·검증 기준을 구체화하며, 사실을 추가하거나 의무·확신도를 바꾸는 허가가 아니다.

## 실행

- 개선점만 요청하면 review, 말투 교정이면 polish, 재구성·축약을 요청하면 adapt로 진행한다. 세부 의미와 검증은 공통 계약을 따른다.
- 사용자 입력에서 목적과 제약이 분명하면 추가 질문 없이 진행한다. 부족한 사실은 작성하지 않고 확인 사항으로 남긴다.
- 이 용도의 규칙에 따라 검토/수정한 뒤 원문과 대조한다. 일반적인 글쓰기 원칙을 맞추기 위해 이미 적합한 문장을 바꾸지 않는다.
- 혼합 작업은 필요한 다른 파생 스킬의 규칙 파일만 읽고 구획별로 적용한다. 모든 파생 스킬을 매번 로드하지 않는다.
- 결과 형식과 설명 길이는 공통 계약의 결과 절을 따른다. 수정이 없으면 원문과 이유 한 문장으로 끝내고, 관례적인 추가 질문은 붙이지 않는다.

공개 자료의 출처는 [공통 출처 원장](../my-writing-base/references/sources.md)에서 확인한다.
